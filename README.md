# Amazon Sales Data Analytics

## Project Overview
This project focuses on analyzing Amazon sales data to understand sales performance, customer order trends, and product category performance.

## Tools Used
- Excel
- SQL
- Data Cleaning
- Data Visualization

## Project Objectives
- Analyze sales trends
- Calculate key performance indicators
- Identify top-performing categories
- Analyze city-wise sales
- Build a sales dashboard

## Dashboard
Includes KPI cards, monthly sales trends, and category-wise sales visualizations.
